## What stops the card

Two existing tests use the path index as an index that the mirror does not serve. Their premise no longer holds, and the builder does not edit them:

- `crates/zoe-catalog/tests/mirror.rs`, `an_option_that_the_mirror_does_not_serve_gives_a_refusal`: it expects `{"c": [{"k": "p", "i": "path"}]}` to be an unknown kind (`PlanError::Unknown`). The kind `p` is known now, and that clause lacks its keys, so it is `Malformed`. Proposed fix: the text clause of ADR 0060, `{"c": [{"k": "t", "i": "SearchableText"}]}`, which stays unknown until that card.
- `python/zoedb/src/zoe/plone/tests/test_catalog_mirror.py`, `test_a_text_query_and_an_index_out_of_the_skeleton_take_the_python_path`: `path="/plone", portal_type="Document"` is native now, so the counts are 2 Python searches, not 3. Proposed fix: `Description="Item", portal_type="Document"` (a ZCTextIndex, `index`).
