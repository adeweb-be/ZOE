## Open: one test of plone.restapi fails with the guard

`just plone zoe suites`: 2975 tests, 0 failures, 1 error: `plone.restapi.tests.test_addons.TestAddons.test_install_specific_profile` raises `ReadConflictError` at the `transaction.commit()` of the test. It passes on this branch with the guard taken out of `zoe.plone.testing.install()`, and `main` has no guard. The cause: the test transaction read the registry, so the guard called `readCurrent` on it. The request of the test imports a profile, and the subscribers of Products.CMFPlone and plone.app.theming then set `__RESOURCE_REGISTRY_MTIME` and `_theme_cache_mtime` on the registry object itself. Zope retries such a conflict in a request, but the test has no retry.

A narrower guard is possible: the move also writes the root objects of `_fields` and `_values`, and the guard calls `readCurrent` on those roots, not on the registry object. A write of a record that races a move still conflicts, and a write of an attribute of the registry object no longer conflicts with every reader. This changes sections 1 and 5 of the accepted ADR 0050, so it waits for a decision.
