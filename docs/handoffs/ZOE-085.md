## What failed

The acceptance test does not compile:

```text
error[E0499]: cannot borrow `rng` as mutable more than once at a time
   --> crates/zoe-server/tests/fuzz_smoke.rs:179:45
179 |         let input = mutate(&mut rng, &seeds[rng.below(seeds.len())]);
```

The first argument borrows `rng` mutably, and the second argument uses `rng` again. Rust refuses this in every edition. No change outside the test can make it compile. So `just check` (clippy on all targets) and `just test` fail on the branch too.
