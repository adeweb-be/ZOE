Reproduce

In a checkout of the ZOE repository, inside devenv shell, one command runs the published set on one machine: B5 on the fixtures small and medium with the stacks zeo and zoe-native-qi-kv, the native gate and the client benchmark. It resumes after a stop.

just bench showcase --plan    # each run of the set and its estimate; runs nothing
just bench showcase           # writes target/bench/showcase/<started>/

zodbshootout runs on its own: just bench writes target/bench/results. Then just bench publish checks each document and copies it into a checkout of the results repository, with this page:

just bench publish target/bench/showcase/<started> CHECKOUT

It takes only a full run of a clean tree at a commit of main, and for B5 only verified runs. It never commits and never pushes. The harness and what it measures: bench/README.md.

Results: adeweb-be/zoe-bench-results. Harness, schemas and the source of this page: bench/ in the ZOE repository.
